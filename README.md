# 🩺 MediAssist AI

> A production grade Medical Research Assistant powered by Large Language Models (LLMs), Retrieval Augmented Generation (RAG), LangGraph, and FastAPI.

## 📖 Overview

MediAssist AI helps researchers and healthcare professionals interact with medical literature using natural language. Users can upload research papers, ask questions, generate summaries, and receive evidence-backed answers with citations.

The goal of this project is to demonstrate how modern AI systems can be built using production-ready software engineering practices.
